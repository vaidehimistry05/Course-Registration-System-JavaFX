# 🎓 Course Registration System (JavaFX)

## 📌 Overview

The Course Registration System is a JavaFX-based desktop application that simulates a complete course enrollment workflow. Users can browse available courses, register through a validated registration form, watch course video lectures, and receive a personalized course completion certificate upon successfully completing a course.

The project demonstrates JavaFX GUI development, event handling, multimedia integration, input validation, and file handling using Java.

## 📝 Registration Form

The registration form collects the following information:

- Name
- Role (Student / Teacher / Other)
- Contact Number
- Email Address
- Institute Name
- Education
- Course Selection

---

## ✅ Input Validation

The application validates user input before registration.

Validation includes:

- All fields are mandatory.
- Contact number must contain only digits.
- Email address must contain '@' and '.'.
- A role must be selected.
- Education must be selected.
- Course must be selected.

User-friendly warning dialogs are displayed whenever invalid input is detected.

---

## 🎥 Video Lecture Module

After successful registration, the selected course lecture opens automatically.

Features include:

- Play
- Pause
- Stop
- Forward (+10 seconds)
- Backward (-10 seconds)

---

## 🏆 Certificate Generation

Once the course is completed, the application automatically generates a personalized course completion certificate.

The certificate is exported as a PNG image containing:

- Student Name
- Selected Course
- Completion Date

---

## 💾 File Handling

The project demonstrates Java File I/O by storing student registration details in a text file.

Generated Files:

- students.txt
- Course Completion Certificate (.png)
